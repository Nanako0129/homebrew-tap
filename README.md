# homebrew-tap

Homebrew casks for Nanako0129's macOS apps.

| App | Install |
|---|---|
| [Syrtis](https://github.com/Nanako0129/syrtis) | `brew install --cask nanako0129/tap/syrtis` |
| [limpet](https://github.com/Nanako0129/limpet) | `brew install --cask nanako0129/tap/limpet` |

Both apps update themselves with Sparkle (`auto_updates true`), so `brew upgrade` leaves them alone unless you pass `--greedy`.
